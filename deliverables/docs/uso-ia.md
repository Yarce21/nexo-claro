# Nota de uso de IA

Se utilizó Codex para proponer arquitectura, implementar TypeScript y React, generar datos totalmente ficticios, escribir pruebas y documentación, y ejecutar verificaciones y grabación automatizada del navegador.

La aplicación no llama a modelos ni usa claves de IA: clasifica con reglas deterministas externas. Las decisiones pueden inspeccionarse mediante motivos, versiones y auditoría. Los resultados de las pruebas y los límites de las mediciones se documentan. No se accedió a cuentas, datos ni servicios de Influgain.

Antes de presentar la entrega, el candidato debe recorrer la demo y poder explicar las decisiones, límites y fallos. Esta nota declara el uso de IA; no afirma una revisión humana que todavía no haya ocurrido.
