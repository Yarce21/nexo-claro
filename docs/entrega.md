# Lista de entrega

## Incluido

- Repositorio Git local y fuentes completas con lockfile.
- README con instalación, comandos, contratos de API y recorrido del evaluador.
- 48 leads ficticios, reglas JSON externas, CSV de 30 filas sucias y 10 fuentes.
- Agente determinista con contexto, cola humana, revisión de casos sensibles y auditoría.
- Cinco disposiciones, outbox aprobada, partner HTTP ficticio, reintentos y fallos.
- Conciliación fila por fila, métricas, leads estancados y análisis de comisiones.
- Tres guiones priorizados y vinculados a sus fuentes.
- Export de estados y auditoría, CSV limpio, métricas y capturas.
- Video subtitulado de menos de seis minutos.
- Notas de decisiones, escala y uso de IA.

## Acciones personales del candidato

1. Recorrer la demo y entender las decisiones antes de presentarla.
2. Publicar el repositorio en la cuenta que elija y comprobar el enlace sin sesión. No hay remoto configurado porque no se proporcionó una URL.
3. Adjuntar o compartir el video, export y repositorio con el evaluador.
4. Verificar el enlace 404 del proyecto de fidelización: pertenece a otro proyecto, no se modificó.
5. Enviar personalmente el correo de inicio y controlar el plazo de 72 horas desde ese envío. No se envió ningún correo ni se inventó una fecha de inicio.

La demo corre en localhost; ese enlace no sirve al evaluador remoto. Para entrega sin hosting, usar la opción autorizada por el enunciado: export + video y repositorio reproducible. Una publicación pública de esta consola requiere autenticación y ajustes de seguridad previos.
